# 개발자 웹 이력서 개발 로드맵

개발자 본인을 소개하는 싱글 페이지 웹 이력서를 만든다.

## 기술 스택

- HTML5: 페이지 구조와 시맨틱 마크업
- CSS / Tailwind CSS: 스타일링과 반응형 레이아웃
- JavaScript: 인터랙션 (메뉴, 다크 모드 토글, 스크롤 효과 등)

## 이력서 구성 (일반적인 내용)

1. 헤더: 이름, 직무(예: 프론트엔드 개발자), 한 줄 소개, 연락처
2. 소개 (About): 간단한 자기소개 3~4문장
3. 기술 스택: 사용 가능한 언어, 프레임워크, 도구를 항목별로 정리
4. 경력: 회사명, 기간, 직책, 주요 업무
5. 프로젝트: 프로젝트 이름, 기간, 사용 기술, 역할, 성과 (2~3개)
6. 학력 및 자격증
7. 연락처 및 링크: 이메일, GitHub, 블로그 등
8. 푸터: 저작권 문구

## 디렉터리 구조 (예정)

```
.
├── index.html        # 이력서 메인 페이지
├── css/
│   └── style.css     # Tailwind 빌드 결과 또는 추가 스타일
├── js/
│   └── main.js       # 다크 모드, 메뉴 등 인터랙션
├── assets/           # 이미지, 아이콘, 프로필 사진
└── ROADMAP.md
```

## 개발 단계

### 1단계: 준비 (기획 및 환경 설정)

- [ ] 이력서에 들어갈 본인 정보 정리 (소개, 경력, 프로젝트, 기술 스택)
- [ ] 디자인 방향 결정 (색상, 폰트, 레이아웃 참고 사이트 수집)
- [ ] 프로젝트 폴더 및 파일 생성 (`index.html`, `css/`, `js/`, `assets/`)
- [ ] Tailwind CSS 설정 (CDN 또는 CLI 빌드 방식 선택)

### 2단계: 마크업 (HTML 구조 작성)

- [ ] 시맨틱 태그로 기본 골격 작성 (`header`, `main`, `section`, `footer`)
- [ ] 헤더 섹션: 이름, 직무, 한 줄 소개, 연락처
- [ ] 소개 섹션 작성
- [ ] 기술 스택 섹션 작성
- [ ] 경력 섹션 작성
- [ ] 프로젝트 섹션 작성 (카드 형태)
- [ ] 학력 및 자격증 섹션 작성
- [ ] 연락처 및 링크 섹션, 푸터 작성

### 3단계: 스타일링 (Tailwind CSS)

- [ ] 전체 레이아웃 및 타이포그래피 설정 (폰트, 색상 변수)
- [ ] 섹션별 여백과 구분선 스타일링
- [ ] 기술 스택 뱃지 / 태그 스타일링
- [ ] 프로젝트 카드 hover 효과
- [ ] 반응형 디자인 적용 (모바일 / 태블릿 / 데스크톱)
- [ ] 다크 모드 색상 정의 (`dark:` 클래스 활용)

### 4단계: 인터랙션 (JavaScript)

- [ ] 다크 / 라이트 모드 토글 버튼 구현 (`localStorage`에 설정 저장)
- [ ] 모바일 햄버거 메뉴 구현
- [ ] 상단 네비게이션 클릭 시 해당 섹션으로 부드럽게 스크롤
- [ ] 스크롤에 따라 현재 섹션 메뉴 강조 표시
- [ ] 섹션 등장 시 페이드인 애니메이션 (선택 사항)

### 5단계: 최적화 및 점검

- [ ] 이미지 용량 최적화 및 `alt` 속성 작성
- [ ] 시맨틱 마크업 및 접근성 점검 (키보드 탐색, 명도 대비)
- [ ] 다양한 브라우저 및 기기에서 동작 확인
- [ ] 메타 태그 작성 (`title`, `description`, Open Graph)
- [ ] 콘솔 에러 및 링크 점검

### 6단계: 배포

- [ ] GitHub 저장소 생성 및 코드 업로드
- [ ] GitHub Pages, Netlify, Vercel 중 하나로 배포
- [ ] 배포 URL 확인 후 이력서 링크 공유

## 완료 기준

- 모든 섹션이 모바일과 데스크톱에서 깨지지 않고 표시된다.
- 다크 모드 토글과 메뉴 인터랙션이 정상 동작한다.
- 배포된 URL로 누구나 접속할 수 있다.
